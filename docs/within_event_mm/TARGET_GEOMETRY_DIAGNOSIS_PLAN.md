# 第四因素：目标尺寸与背景占比的专项诊断方案

制定2026-10-26，所有分组规则在读取本次几何—错误关联结果之前规定。
实验卡：[target_geometry](../../reports/within_event_mm/target_geometry/README.md)。

## 问题与验证路径

错例中房屋小、背景显眼是候选解释，单看几个截图不足以确定影响范围。
先在固定共同val的9014栋建筑上，检查错误是否与几何尺寸相关，分事件和
真实类别控制。该步骤是已有固定模型的错误诊断，不重新训练、不改输入。
第二因素均衡策略未获支持，本轮仍分析自然遍历匹配A，而不是把候选叠加。

## 几何定义与分组

只用train/val清单的post_bbox，宽高按原dataset规则至少1像素；
原裁剪边长s=max(2,ceil(max(w,h)+32))。定义原生bbox面积w*h、
bbox在裁剪中的面积比例w*h/s²。后者只是矩形代理，不是真正建筑轮廓或
邻屋/植被像素占比；它也同时受到细长形状影响，不能独称背景因果。

分别对这两个指标，用train在每个事件内的25%、75%分位点固定阈值；
val分为低组(<=Q1)、中组、高组(>=Q3；重合边界归低组优先)。不根据
错误率重新挑阈值。低面积或低占比是本轮预定关注组，高组为对照。
报告每个事件×真实类别×组的支持数、B1/B2错误数和错误率，另给全部
可同时观察低/高组的事件×类别层等权平均错误率差。空层标明缺失；
小样本层保留数量，不能把汇总差当因果或独立样本显著性结论。

## 共同benchmark和来源验收

固定manifest/split_map/data_lock与共同协议哈希。预测使用第二因素匹配A
的B1/B2完整val导出，核对evaluation.json中summary、checkpoint和
predictions哈希、val9014、test_evaluated=false，逐栋与val清单连接。
拒绝重复、缺失、标签冲突或非val预测。单元检查已知bbox几何、边界分组、
非法bbox及重复预测拒绝。不访问影像、不触及test建筑的几何或标签统计。

## 判读与下一阶段

如果小尺寸/低占比错误在控制地区和类别后仍方向一致，作为裁剪干预的
设计依据，但仍不能证明是唯一原因。两模型或两指标方向不一致、支持数
稀少时完整报告，不强行训练。任何后续裁剪实验另写干预方案和实验卡，
只改变一个裁剪策略；保持同一val建筑、标签、20轮、模型/种子与评分，
使用单独缓存并验证像素、样本顺序和恢复一致性。不在诊断后搜索最好分组。

## 产物与局限

逐栋派生记录如需生成留output。记录工具/计划/输入哈希。此诊断没有
