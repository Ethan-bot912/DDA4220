# 第六因素：B2两时相比较结构独立实验方案

2026-10-26，先制定方案再实现。实验卡：
[b2_structure/README.md](../../reports/within_event_mm/b2_structure/README.md)。

## 1. 问题、证据和假设

共同自然A的B1 Macro F1为0.664257，B2为0.652521；加入灾前图并未自动改善。
既有B2把pre/post直接沿通道拼成6通道，只有第一层融合，没有显式特征差分。
这为结构对照提供动机，但分数差不能证明结构有错。第五因素配准诊断未能支持可靠
自动校正，因此本轮不改图像对齐，单独检验一种明确的特征比较结构，不搜索架构。

## 2. 唯一主要改动与对照

A：原B2，pre/post六通道早期拼接ResNet18。B：共享参数的三通道ResNet18编码器，
对同一batch的pre和post沿batch维拼接后一次编码，得到f_pre、f_post（各512维），
将[f_post, f_post-f_pre]（1024维）送入线性四分类头。
这是一种有符号特征差分候选；不增加注意力、配准、增强或额外损失。
共享编码器的BatchNorm在混合pre/post的2B输入上更新，是本架构的一部分，必须披露。

本轮只训练A-B2和B-B2各一次，seed42、attempt01，各20轮；B1不变，仅引用
已验收共同A作为背景参照，不把B-B2减B1称本因素收益。本轮重建匹配A，
额外检查其完整轨迹与前轮A一致；科学主比较始终是本轮B减本轮A。

## 3. 共同benchmark和固定条件

Matthew/Moore事件内，按影像块固定分组，train26976、val9014、test9012继续封存。
同一manifest/split_map/data_lock及原context16精确uint8缓存；原逆频率权重、
自然遍历、无增强、128px、batch32、float32、随机初始化、AdamW lr.001/wd.01、
20轮cosine、pooled val Macro F1严格提升选单个best，所有地区来自同一best。
workers4/prefetch2/pin_memory，准确续训要求沿用既验收实现。
不叠加前面五因素的候选，val身份和argmax评分不变。

## 4. 初始化、公平性与计算预算

相同seed先生成同一完整三通道ResNet18。A按原规则把conv1权重复制一份并除以2；
B保留三通道编码器并新建1024→4分类头。两种结构张量形状不同，不能要求全模型
初始化哈希一致；检查共享残差层初始参数完全一致，记录各自初始化哈希及参数量。
分类头初始化和BatchNorm输入分布随结构变化，不能把本轮结果解释为纯数学减法效应。

以相同20轮、相同建筑曝光和优化步数匹配，而非声称相同FLOPs或时间。
候选编码两张图可能接近双倍计算，必须报告实际秒数和峰值显存。
先用128px合成batch32测训练步耗时估计候选完整20轮，再加A实测约27分钟、
demo/导出/分析及至少15分钟收尾；若超过07:50则不启动正式队列，不缩短20轮。
启动后截止在epoch边界保存，未完成结果不能充当完整比较。
