# 第五因素：灾前灾后位置对齐专项诊断方案

制定于2026-10-26，先于实现和真实图像诊断。实验卡：
[alignment/README.md](../../reports/within_event_mm/alignment/README.md)。

## 1. 问题与可检验范围

前后外观差异可能来自真实灾害，也可能来自位置偏移。不能把相关性低直接叫作错位，
更不能按不可靠估计平移全体图片。本轮先检查小范围平移估计在已知答案上是否可靠，
再在固定benchmark允许的train/val缓存上做质量诊断，暂不训练或校正。

本轮只诊断128px、context16既有裁剪上的相对平移，不证明原始整幅影像的配准精度；
尺度/旋转、视角、季节、遮挡和真实损毁均可能使该平移模型失效。

## 2. 固定数据与隔离

沿用封存manifest/split_map/data_lock，Matthew/Moore按影像块分组。
train26976、val9014，同事件test9012及项目封存事件不读取影像、不评分。
只读已验证context16的train/val uint8缓存，manifest身份顺序核对；不另裁剪、不改标签。
验证错误来自第二因素自然A的完整B1/B2最佳checkpoint导出，保持同一val建筑身份。

## 3. 方法与预先固定的诊断参数

将RGB均值灰度图的一阶梯度作为特征，穷举dx/dy为[-8,8]的整数平移，
以固定中心96x96窗口的去均值归一化相关系数选择最佳位置。
dx/dy定义为post中对应pre像素的位置偏移；使用同一中心范围，避免不同位移改变样本数。
记录最佳相关、零位移相关、改善幅度、最大轴位移和次优峰差。
次优峰排除最佳周围Chebyshev距离<=1的邻域；梯度标准差过低(<1e-4，灰度0到1)拒绝。
可信候选的固定条件：最佳相关>=0.5、与次优峰差>=0.05、两轴均未触边。
疑似偏移还需最大轴位移>=2、最佳相对零位移相关改善>=0.10。
阈值仅是保守筛查规则，不是已知真实错位标签；不根据val误差调参数。

为控制耗时，以事件×类别为层，seed42按身份排序后固定随机抽取train每层最多32栋、
val每层最多64栋；小层全取。报告实际覆盖及样本身份，结果不能当全val的发生率。
每栋先做同图合成位移，之后才看真实pre/post，测量该建筑是否具备可估计纹理。

## 4. demo与方法门槛

先在合成随机纹理、规则纹理、常量图上测试：0、(3,-2)、(-4,5)、(8,0)已知位移；
位移用非循环零填充，不使用np.roll制造周期捷径。
随机纹理中间位移应准确恢复，常量图必须拒绝，边界位移须标记不可信。
再在每个入选真实pre裁剪上合成(3,-2)，若该层恢复率<90%，该层真实估计只列不确定。
即使合成通过，真实损毁仍可使方法失效；可信筛查也只叫疑似。
检查亮度比例变化与中央区域替换的合成压力测试，保留失败，不更换参数追求通过。

## 5. 真实诊断与验收

逐样本写身份、估计量、合成恢复、可信/疑似标记、B1/B2是否出错。
按事件×真实类别报告覆盖、拒绝数、合成成功率、疑似数和偏移分布。
对合成方法通过的层，比较疑似与非疑似的现有固定模型错误率，保留空组/小支持。
只有两组均>=10才提供分层差及等权分层均值；附tile数防止建筑重复被误当独立证据。
不以诊断差值称因果效应或性能提升。输出计划/源码/缓存/预测来源哈希及机器可读审计。

如缺乏可靠错位证据，结论为诊断不确定，不启动校正训练；如果出现一致可靠线索，
另立校正干预方案与实验卡，保留所有共同条件再验收demo/正式20轮。
