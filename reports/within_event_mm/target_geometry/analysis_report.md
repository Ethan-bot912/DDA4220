# 第四因素：目标尺寸与背景占比专项诊断

状态：固定模型诊断完成；尚无新的训练收益。几何及连接检查两项测试通过。

| 模型 | 小原生面积组减大面积组错误率（百分点） | 低bbox占比组减高占比组（百分点） |
| --- | ---: | ---: |
| b1 | +4.071 | +7.095 |
| b2 | +1.724 | +6.098 |

阈值只由train各事件内四分位点确定；错误率差按8个事件×真实类别层等权平均。
两模型在这两种汇总指标上方向一致，支持继续检验一个裁剪候选，但证据不强：
Matthew摧毁类方向相反；Moore某些低/高组只有8到19栋，等权结果容易受小组影响。
不能据此声称背景已被确定为错误原因，也没有独立样本显著性检验。

矩形bbox占比不是屋顶分割占比；原生面积与占比也相关。后续只测试一个
预先固定的候选：context从16降到8，输出仍128px。它同时减少周围视野、
提高目标在输出中的尺寸，结果只能归于该裁剪策略，不能单独分解背景/分辨率。
将为此另写干预方案和实验卡，沿用同一val建筑集合、固定20轮与匹配A。
