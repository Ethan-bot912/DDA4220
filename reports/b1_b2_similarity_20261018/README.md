# B1 与 B2 Macro F1 接近的原因分析

本次分析只使用现有的两份最佳权重（B1 第 5 轮、B2 第 9 轮）及其验证集预测，没有重新训练，也没有做扩大实验。

**结论：B2 确实利用了灾前图，而且在受损建筑上明显比 B1 好。但它对完好建筑的误报更多，验证集里完好建筑又占 87%，两边一抵消，Macro F1 就几乎一样了。**

## 1 输入与代码检查

- B2 的输入是灾前 3 通道加灾后 3 通道，拼成 6 通道。两张图用同一个裁剪窗口，没有发现拼接错误。
- 在按类别抽样的 2,649 栋验证建筑上，只改 B2 的灾前输入，性能下降很明显，说明 B2 真的在用灾前图（`results/ablation_subset.json`）。

| B2 的灾前输入 | Macro F1 |
| --- | --- |
| 正常 | 0.704 |
| 换成其他建筑的灾前图 | 0.543 |
| 换成灾后图（等于"没有变化"） | 0.332 |
| 置零 | 0.135 |

在这个抽样集上，B1 的 Macro F1 为 0.667。抽样集按类别重新平衡过，数字不能和完整验证集直接比较。

## 2 完整验证集：Macro F1 一样，但两个模型错在不同地方

完整验证集为 moore-tornado，共 22,372 栋（`results/per_class.csv`，`results/confusion_b1.csv`，`results/confusion_b2.csv`）。

| 指标 | B1 仅灾后 | B2 灾前+灾后 |
| --- | --- | --- |
| Macro F1 | 0.601 | 0.602 |
| 平衡准确率 | 0.668 | **0.713** |
| 轻度损毁召回率 / 精确率 | 0.34 / **0.36** | **0.47** / 0.26 |
| 重度损毁召回率 / 精确率 | 0.50 / **0.36** | **0.67** / 0.28 |
| 完全摧毁召回率 / 精确率 | **0.91** / 0.56 | 0.81 / **0.68** |
| 完好建筑被误判为轻度损毁 | 509 | **1,105** |
| 完全摧毁被判为重度损毁 | 44 | **218** |

两个模型共有 2,778 栋预测不同，按真实类别统计哪一方判对（`results/disagreement_winner.csv`）：

| 真实类别 | B1 对 | B2 对 | 都错 |
| --- | --- | --- | --- |
| 完好 | **1,085** | 664 | 277 |
| 轻度损毁 | 52 | **166** | 99 |
| 重度损毁 | 36 | **112** | 13 |
| 完全摧毁 | **201** | 48 | 24 |

完好建筑在验证集里有 19,453 栋，占 87%。B2 只要把其中几个百分点误判成轻度损毁，误报数就会超过真正的轻度损毁（886 栋），拉低轻度和重度两类的精确率。Macro F1 对这一点很敏感，平衡准确率则能看出 B2 更好。

## 3 B2 误报多的主要原因：验证事件的"正常变化"本来就更大

下表是每栋建筑灾前与灾后图像的平均绝对像素差（像素值缩放到 0–1 后的中位数，见 `results/change_by_event_class.csv`）。

| 事件 | 完好 | 轻度 | 重度 | 完全摧毁 |
| --- | --- | --- | --- | --- |
| joplin-tornado（训练） | 0.064 | 0.079 | 0.101 | 0.128 |
| moore-tornado（验证） | **0.082** | 0.094 | 0.114 | 0.138 |
| lower-puna-volcano（训练） | 0.089 | 0.101 | 0.092 | 0.128 |

- 在 moore 里，完好建筑的变化量已经超过 joplin 轻度损毁的水平，灾后图整体也更亮（亮度差中位数：moore +0.021，joplin −0.014）。B2 从 joplin 学到的"变化多大才算受损"，搬到 moore 上就偏低了。
- 把完好建筑按变化量从小到大分成五组，变化最大的那组里，B2 误报率为 20.8%，B1 为 14.3%。变化较小的几组里两者差不多（`results/no_damage_false_alarm_by_change.csv`）。B1 不看灾前图，所以受影响较小。
- 误报集中在少数影像上：两个模型都有约一半的误报来自 10% 的影像。这更像整张图的成像差异（光照、季节、配准），不是个别建筑的问题。
- 推测，尚未验证：灾前与灾后可能存在几个像素的错位。用相位相关估算，完好建筑的位移中位数在 moore 约为 2 像素，在 lower-puna 约为 6 像素，会产生"假变化"。

## 4 训练数据和模型结构的限制

- **轻度和重度样本几乎全来自 joplin 一个事件。** 训练集里轻度和重度共 3,272 栋，lower-puna 只占 75 栋。B2 等于只从一个事件学会了"中间损毁程度长什么样"，很难迁移到别的事件。
- **lower-puna 是火山熔岩，损毁形态和龙卷风完全不同。** 它的完好建筑变化量也偏大，会让模型以为"有变化也可能是完好"，干扰学习。
- **过拟合明显。** 训练损失从约 0.9 降到 0.01，最佳轮次却是 B1 第 5 轮、B2 第 9 轮，说明两个训练事件能提供的有效信息有限。
- **B2 的融合方式比较简单。** 灾前和灾后只是拼成 6 通道送入同一个网络，没有显式计算差异，也没有预训练权重。第一层卷积由 B1 的权重复制两份再除以 2 得到，训练开始时只看到灾前灾后的平均。训练后两半权重的相关系数为 0.098，已经脱离对称起点，但对亮度和错位带来的假变化没有抵抗力。
- **只有一个随机种子。** 0.601 与 0.602 的差距远小于换种子可能带来的波动。

## 5 建议

1. 报告时除了 Macro F1，同时给出平衡准确率和每类的召回率、精确率，这样 B2 的优势才能体现出来。
2. 不训练也能验证第 3 节：对每对灾前灾后图做亮度或直方图对齐，再用现有权重重新推理 B2，看误报是否下降。
3. 调整完好类的判定阈值时，需要另外留出数据来调，不能直接在验证集上调。
4. 之后如果改模型，可以在输入里加入灾后减灾前的差分，或改成两个分支分别提取特征后再比较（孪生结构），同时多跑几个种子。

## 6 复现

需要先按 [REPRODUCE_AND_DIAGNOSE.md](../../REPRODUCE_AND_DIAGNOSE.md) 准备验证影像和两份最佳权重。在仓库根目录运行：

```bash
python reports/b1_b2_similarity_20261018/scripts/diag.py         # 第 1 节消融，抽样 2,649 栋
python reports/b1_b2_similarity_20261018/scripts/diff_stats.py   # 第 3 节变化量统计，写入 output/diagnosis/diff_stats.csv
python reports/b1_b2_similarity_20261018/scripts/compare_b1_b2.py  # 生成 results/ 下的汇总表
```

本次运行环境为 CPU 推理（Python 3.13，torch 2.11）。验证影像取自公开镜像 `hannan022/xview2-xbd`，是 PNG 转成的 GeoTIFF，和官方文件不是同一字节。复评得到 B1 Macro F1 0.6020、B2 0.6023，与原记录（0.6012 / 0.6023）基本一致。上面的表格使用仓库自带的原始验证集预测（`output/resnet18/*_val.csv`）。第 3 节的变化量统计覆盖全部验证建筑，以及随机抽取的 5,000 栋训练建筑。
