# 课程 paper 写作入口

这里组织课程文章及补充材料。目前尚未发布正式 paper，课程模板、篇幅、截止日期与评分要求待团队确认。[初始 proposal](../reports/proposal.md)保留在原位置。

## 写作与证据

先维护[证据对应表](evidence_map.md)，再形成文章。主文按问题、方法、实验、讨论组织；研究时间线见[研究历史](../docs/research_history.md)，不必逐次训练写成流水账。

可考虑的内容：B1/B2 受控比较、跨事件差异、未来事件内诊断、候选因素对照、多 seed、效率与限制。自动建筑定位、其他融合和展示功能以实际完成程度决定是否纳入。

## 文件归属

确定格式后，正文源码放本目录；参考文献放 `references.bib` 或格式对应文件；最终图表可放 `figures/`，并在证据表记录来源实验、运行、生成方式。补充材料可放 `supplement/`。按需创建，不提交空目录或重复的大型数据。

已有每项实验的完整分析继续放 `reports/`。Paper 引用同一来源的数字，复制图表时标明来源版本，避免手工维护互相不一致的表格。正式 PDF 作为清楚命名的交付物发布，保留可编辑源码与生成说明。

## 结论边界

val 开发与选优成绩、诊断子集、完整验证集和最终 test 分开。多 seed 报告预先计划与实际完成集合，缺失和中止不隐藏。事件内结果不能代替跨事件泛化证据，效率倍数绑定设备与协议。初始 proposal 到后续研究的范围调整在文章中说明。
